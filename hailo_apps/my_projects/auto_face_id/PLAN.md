# План объединения object detection и face recognition

Этот файл служит рабочим планом и источником истины для текущей задачи.  
По мере выполнения пункты нужно переводить в `- [x]`.

## Что уже есть

- [x] Программа для `object detection`, которая находит человека
- [x] Программа для `face detection` и `face recognition`, которая умеет определять лицо и присваивать `global_id`

## Текущая задача

Объединить две существующие программы в одно решение, которое будет работать на AI HAT Hailo-10H:

- сначала определять человека;
- затем находить у этого человека лицо;
- если лицо новое, делать несколько снимков и присваивать ему `global_id`;
- если лицо уже известно, определять, кто это, и связывать человека с его `global_id`.

## План работ

- [ ] Встроить `object detection` и `face recognition` в один пайплайн
  - Передавать данные о найденном человеке в логику поиска лица.
  - Связывать найденное лицо с конкретным человеком.
- [ ] Реализовать присвоение `global_id`
  - Для нового лица собирать несколько снимков.
  - Создавать новый `global_id` для неизвестного человека.
  - Для известного лица находить уже существующий `global_id`.
- [ ] Проверить работу на AI HAT Hailo-10H
  - Убедиться, что объединённая программа стабильно работает на Raspberry Pi 5 с AI HAT Hailo-10H.
  - Проверить, что pipeline использует нужные Hailo-модели и не ломает текущую логику.
- [ ] Протестировать объединённую программу
  - Проверить появление нескольких людей.
  - Проверить новое и уже известное лицо.
  - Проверить повторное появление человека в кадре.

## Следующий этап

После завершения объединения программ следующим шагом будет задача, где люди идут по коридору, и система должна определять, какой человек вошёл.
